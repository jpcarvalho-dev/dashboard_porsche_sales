# dashboard_porsche_sales
Dashboard de vendas Porsche em HTML, CSS e JavaScript (arquivo único).

**Perguntas:** 1) principais modelos por cidade; 2) ano-modelo que mais saiu no período; 3) carros mais populares em cada cidade.

**Tratamento:** só colunas sanitizadas, preço e ano em número, 24 datas `INVALID` mantidas e coluna "família" criada a partir do modelo.

**Prompt:** "Crie uma dashboard HTML com filtros de modelo, ano-modelo, cidade e pagamento, no estilo da Porsche, respondendo às 3 perguntas acima."

**Ferramenta:** Claude (Anthropic).
